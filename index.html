l.loaf chat

Loaf Chat, fresh out of the oven

An early build for testers: chat with your crew on loaf.moe, from your own computer.

version 0.1.17 · macOS, Windows & Linux

macOS

macOS 12 or newer, Apple silicon or Intel.

download for mac

Open the .dmg and drag Loaf Chat into Applications.

Windows

Windows 10 or 11, 64-bit Intel or AMD.

download for windows

This early build isn't signed, so Windows warns about it. Choose More info, then Run anyway. It installs just for you and never asks for admin. If Smart App Control blocks it outright, it can't run on that PC yet.

Linux

64-bit Intel or AMD.

install with flatpak get the AppImage
flatpak install https://get.loaf.moe/loaf-chat.flatpakref

Keep the AppImage somewhere you can write to, like ~/Applications, so it can update itself.

It keeps itself fresh

Loaf Chat fetches new builds on its own. When one's ready, a little tile appears at the bottom of your spaces rail. Restart whenever suits you, or just quit and it's there next time.

Found a crumb out of place? Tell us in #feedback:loaf.moe.
